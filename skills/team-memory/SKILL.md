# Team memory

Use the bounded GitHub read tools to inspect immutable source and pull-request
revisions. Retrieve wiki knowledge only at a reported snapshot. Prepare a
durable proposal with exact page content, hashes, source evidence, and
limitations. This skill is read-only: it cannot publish, push, merge, close
issues, or deploy.

The maintained wiki is traditional human-readable documentation, not a
transcript, embedding store, or automatic PR log. Make no change when source
evidence has no durable knowledge impact. Conflicting or incomplete evidence
requires human review.
